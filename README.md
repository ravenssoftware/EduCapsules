# EduCapsules

*Teach safely · Learn in order · Monitor with confidence*

A multi-role educational platform (Teacher, Assistant, Student, Parent, Admin) built to the [EduCapsules Master SRS](docs/srs/README.md).

## Status

**Phase 1 approved; Phase 2 (Repository, CI/CD & Environment Foundation) about to start.** The backend stack (TypeScript, Hono, Drizzle ORM, pnpm, Vitest, Playwright, GitHub Actions) was approved by the Project Owner on 2026-09-13 — see [`docs/decisions/05-phase1-decisions-pending-approval.md`](docs/decisions/05-phase1-decisions-pending-approval.md). **The client is Flutter** (Desktop for V1; the same codebase extends to Android/iOS as a future release), superseding the originally approved React + Vite web client — see [`docs/decisions/06-flutter-client-decision.md`](docs/decisions/06-flutter-client-decision.md). See [`docs/README.md`](docs/README.md) for the full documentation index.
